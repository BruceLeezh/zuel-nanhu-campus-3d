## 分两批的细化清单（每项：改进点 / 参考 / 素材需求）
第一批（视觉收益最大）：
1. **主校门体量**（北门为主，其余门统一风格）：门柱加高到 ~2 层（石砌+压顶线脚），门楣加校名横匾与校徽圆牌，电动伸缩门+道闸+门卫亭（已有）+「机动车道/人行道」分道；侧门简化双柱+道闸。参考 youleyuan.jpg、gta4_waimai.jpg、meipaizhao.jpg。素材需求：北门/东门/南门正面照。
2. **共享电驴停放区**：校园内 8-10 处白线停车区（instanced 电驴 6-10 辆/处，青白配色，参照 xiaoqing_*.jpg），放在宿舍/食堂/教学楼门口；把 nature 的 7 辆单车风格统一。
3. **蓝色指路牌龙门架**：博文路/中南大道、南湖大道/北门、民族大道/东门 3 处（蓝底白字双柱或悬臂，参照 gta_zuoxi.jpg）；文字用 textures.textTexture。
4. **体育场绿色铁丝网围栏**：田径场四周半透明绿网面片 + 立柱（参照 gta_zuoxi.jpg），篮球场同款矮网。
5. **滨湖宿舍区质感**（环湖/滨湖公寓）：石砌挡土墙+铁艺栏杆（有高差处）、楼下电瓶车棚+充电桩、底层架空或车棚连排；参考 gta_dianlu.jpg。
第二批：
6. **曲桥改形**：木曲桥 → 白色石栏杆长直桥（参照 bentai_gaosu.jpg），两端接岸石阶，湖心亭保留在桥侧小岛上。

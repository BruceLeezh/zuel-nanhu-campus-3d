# 资料与数据缺口说明

> 本文件是「中南财经政法大学 · 南湖校区 3D 自由探索页」的数据来源与可信度说明。
> 阅读顺序建议：先看第 0 节的使用限制，再看第 1 节来源、第 2–4 节的「确证 / 推算 / 缺失」三张清单。

## 0. 一句话结论与使用限制

这个校园是**按公开 POI 名称与相对位置重建的示意性 3D 场景**，不是测绘成果、不是导航数据，也不是校方发布的数字孪生。

- 可以用来：校园文化展示、空间方位科普、自由探索体验、教学演示。
- 不可以用来：导航、找路、测绘、工程勘测、施工放线、应急疏散、无障碍通行判断、任何需要精确尺寸或通行规则的用途。
- 场景中的**人物、车辆、树木、座椅、标识牌上的装饰文字、夜景灯光**均为程序化生成或虚构；建筑体量、层数、立面、屋顶形制为按类型推算的近似值。
- 页面不采集、不上传任何数据；不请求外部网络资源（字体、贴图、模型全部内置或程序生成）。

## 1. 数据来源（可复现）

### 1.1 主要来源：百度地图 POI 检索接口

| 项目 | 内容 |
| --- | --- |
| 接口 | `https://map.baidu.com/?qt=s&wd=<关键词>&c=218&rn=10&ie=utf-8&oue=1&res=api`（网页版检索接口的 JSON 返回，`c=218` 为武汉城市码） |
| 采集方式 | `work/bd_search.py` 用 `curl` 直接请求并解析 `content[]` 中的 `name / x / y / addr / uid / std_tag`；`work/bd_collect*.py` 批量拼接关键词，落盘为 `work/bd_pois*.json` |
| 原始结果 | 共约 **192 条**带坐标的检索结果，平铺导出为 `work/poi_local.txt`（每行：名称、`x=`、`z=`、地址或公交线路） |
| 坐标换算 | 接口返回 BD09MC 平面坐标（米制墨卡托）。取 `x/100 * cos(30.48°) ≈ 0.862` 作为东西向缩放，`z = -y/100`（百度 y 轴向北为正，本场景 +z 向南），再整体平移到「五羊广场 = 原点」 |
| 进入布局的条目 | 楼栋、校门、道路、湖、山、广场、食堂、公寓、场馆等有空间意义的名称；公交站、路口、上下车点、周边小区等仅作参考，未建 3D 几何 |

> 说明：该接口是网页端检索接口，不是官方开放平台（无 AK、无配额承诺、无 SLA）。数据为「地图产品展示用 POI」，其坐标本身经过加密偏移，**绝对精度不可保证**；本项目只用它的**名称与相对位置**，并通过整体平移把系统性偏移消化掉。

### 1.2 二手来源：公开网页资料

- 用于交叉核对**名称写法**与**院系/功能归属**：学校官网与院系页面、公开百科条目、校园地图/迎新页、新闻图片中的楼名。
- 用于确认**命名体系**（这一点被完整写进道路命名）：校训「博文明理 · 厚德济世」→ 博文路 / 明理路 / 厚德路 / 济世路；「修身齐家治国平天下」→ 修身路 / 齐家路 / 治国路 / 天下路；「格物致知、正心诚意」→ 格物街 / 正心街 / 诚意街。
- **未使用**：任何官方 CAD 图纸、总平面图、竣工图、航测/无人机数据、校方提供的模型或测绘成果。

### 1.3 仅作人工比对的材料（不参与计算）

`work/map_campus1..4.png`、`work/map_poi.png`、`work/map_search.png` 是检索过程截图，只用于人眼检查「这条路的走向对不对、这个门在哪个方位」，没有从截图里提取任何坐标。

### 1.4 与其他模块的接口

世界数据集中在 `src/world/layout.js`（坐标约定：世界单位 = 米，原点 = 五羊广场，+x 东、+z 南、y 向上）。文件头注释已标注「楼栋平面尺寸与层高为按建筑类型推算的近似值（资料缺口，见 work/campus-sources.md）」，本文件就是那份缺口的展开说明。

## 3. 推算（由类型与常识估计，非实测）

| 对象 | 推算方法 | 误差量级（自评） |
| --- | --- | --- |
| 建筑面宽 / 进深 | 按 POI 名称判断类型（图书馆/教学楼/办公楼/食堂/公寓/场馆/博物馆），套用类型尺寸档位并做少量人工调整 | ±30%～50% |
| 层数与总高 | 类型层高表（如教学 3.9 m、公寓 3.2 m、场馆 6.0 m）× 估算层数 | 层数可能差 1–3 层，高度 ±20% |
| 屋顶形制 | 按类型给 `flat / hip / vault / feature`（如文澜楼等「文」字楼取坡屋顶，场馆取拱顶） | 主观 |
| 立面细节 | 程序化：竖向开窗节奏、勒脚、檐口、材质色（`STYLE_PRESETS` 的 body/trim 色） | 与真实立面无关 |
| 树木数量与分布 | 9 片椭圆林带（`TREE_ZONES`）按 density 程序散布 | 数量 ±50%，种类虚构 |
| 地形起伏 | 4 座丘陵用椭圆高斯叠加（希贤岭 h≈11.5 m 为最高） | 高程 ±2 m |
| 广场 / 绿地形状 | 一律用椭圆（`PLAZAS` 的 rx/rz） | 真实多为不规则多边形 |
| 湖岸线 | 14 点折线（`LAKE.poly`），另加 2 座岛、3 处小水面 | 岸线位置 ±10～20 m，形状被简化 |
| 校园轮廓 | 32 点近似多边形（`CAMPUS_OUTLINE`） | 边界 ±20 m，转角被抹圆 |
| 道路宽度 | 按等级：主干道 24～26 m、次干道 9～14 m、支路 8 m | ±40%，车道数未知 |
| 建筑坐标 | POI 点当作建筑中心；POI 常落在楼门口或楼角 | 中心偏差可达 10～25 m |

> 这些推算都写在代码里、可调：`src/world/layout.js` 的 `STYLE_PRESETS`（层高/开间/颜色/屋顶）与各条目的 `w/d/h` 字段即全部参数。

## 4. 缺失（诚实清单）

**测绘图件类**
- 官方 CAD 总平面图、单体竣工图、竖向设计图、管线综合图、消防总平面。

**建筑本体类**
- 真实层数、层高、建筑面积、结构形式、屋顶坡度与檐口做法；
- 外立面照片级的材质、窗墙比、幕墙分格、色彩编号；
- 各楼实际出入口位置与朝向、门厅进深、无障碍坡道与电梯位置；
- 建筑之间的连廊、架空层、地下车库出入口。

**道路与通行类**
- 车道数、单行/禁行、限速、沥青/铺装材质、路缘石高度；
- 人行道宽度、盲道走向、台阶与坡道、无障碍通行路径；
- 机动车/非机动车停车区、充电桩、共享单车停放点。

**景观与设施类**
- 树木种类、胸径、冠幅、精确点位；花坛、绿篱、雕塑、景石的具体位置与尺寸；
- 座椅、垃圾桶、路灯、监控、指示牌的布置与样式；
- 夜间照明方案（灯具位置、色温、照度、开关时间）；
- 水系的常水位、驳岸做法、桥的跨度与栏杆样式。

**动态与时效类**
- 施工中/新建/改名项目：如「中国会计史文博馆（筹）」的最终体量、外观与开放状态；其他在建楼、临时围挡、道路施工；
- 各楼当前实际使用单位（院系搬迁、楼名调整在高校中很常见）；
- 大型活动、校门开放时间、访客政策。

**范围说明**
- 本项目只覆盖**南湖校区**，不含首义校区及其他校区；
- 校外周边（南湖大道、民族大道沿线、周边社区）只作为背景道路示意，未建模。

## 5. 精度自评（一页速查）

| 维度 | 置信度 | 说明 |
| --- | --- | --- |
| 名称（路/楼/门/湖/山/广场） | 高 | POI + 公开资料双源，个别新楼可能改名 |
| 方位关系 | 中高 | 由 POI 相对位置决定，可放心用于「东边/西北角」这类描述 |
| 建筑中心位置 | 中 | POI 点 ≠ 建筑几何中心 |
| 建筑体量与层数 | 低 | 类型推算 |
| 道路宽度 / 车道 | 低 | 按等级推算 |
| 地形高程 | 低 | 为观感服务的人工起伏 |
| 湖岸线与校园边界 | 中低 | 折线简化 |
| 树木与景观小品 | 极低 | 程序化虚构 |

## 6. 如何复核 / 更新

1. 重跑检索：`python work/bd_search.py "中南财经政法大学 图书馆" "文泰楼" ...`，结果会打印名称与 `x/y`。
2. 换算：`X = x / 100 * 0.862`，`Z = -y / 100`，再减去五羊广场的 `(X0, Z0)` 得到世界坐标。
3. 更新 `src/world/layout.js` 中对应条目的 `x/z/w/d/h`（改完 `node build/build.mjs` 重新出包）。
4. 若拿到更可靠的资料（校方图纸、实地测量、带尺度的卫星影像），优先修正顺序建议为：建筑中心与体量 → 道路走向与宽度 → 湖岸线/地形 → 景观细节。

## 7. 数据伦理

- 只抓取公开检索结果中的**地点名称、地址、坐标**，不涉及任何个人信息；
- 页面不发起网络请求、不写入本地存储之外的任何位置（仅 `sessionStorage` 记录「帮助是否看过」）；
- 所有生成内容（人物、车辆、植被、装饰文字）不指向真实个体或真实事件。

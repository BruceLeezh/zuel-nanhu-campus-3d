## 二、P0 · 明显缺陷（建议下一轮就做）

### P0-1 体育中心立面瓦片换源
- **现象**：南北两面墙带细节几乎看不出，只剩一片灰白；近看是"雾面白墙"。
- **原因**：瓦片源 `crop=(110,52,410,172)` 只有 300×120 px，放大到 512²；且 96m 立面 / 42m 瓦片 = 2.28 次重复，**不整除**，接缝处窗格对不上。
- **建议**：重新裁一张 ≥512×256、含整数开间的瓦片；或按 2.28 取 2.0/2.5 重设 `PHOTO_BAY`，让接缝落在墙垛上。
- **验收**：南、北两面各拍一张，窗带可数、接缝处不出现半扇窗。

### P0-2 逸夫图书馆瓦片裁切相位
- **现象**：两翼每 16m 重复一次，接缝处窗组错半格。
- **原因**：瓦片 512 宽内含约 **3.5 个开间**（不是整数），`baysPerTile=3` 与 `note` 写的 4 也不一致。
- **建议**：重裁一张正好 3 开间（或 4 开间）的瓦片；若短期换不了源，可给 `PHOTO_BAY` 设 5.33×(3/3.5)=4.57m 让整幅对齐，但窗宽会偏窄 14%。
- **验收**：沿立面走一遍，接缝处竖挺连续。

### P0-3 图书馆前广场西侧停车场地面发黑、棋盘感强
- **现象**：`parking-scooters` 区域是深绿黑方格 + 浅色缝，像未渲染的占位图。
- **原因**：铺装贴图在世界坐标 UV 下重复密度过高（约 1.1m 一格），且底色偏深。
- **建议**：该区域单独用「植草砖」贴图，UV 密度降到 3–4m 一格，底色提亮到 `#8a8f7e` 一档。
- **验收**：与五羊广场同屏时不出现"黑洞"。

### P0-4 地标雕塑 / 前景白块
- **现象**：五羊雕塑是纯白几何块，无材质区分，近看像未贴图。
- **建议**：至少给石材/铜/基座三种材质色差 + 环境遮蔽；或整体降饱和成米灰。
- **验收**：3m 距离内能看出"石座 + 主体"两层。

### P0-5 金色「图书馆」招牌被旗杆遮挡
- **现象**：正视角招牌与旗杆重叠，字被切。
- **建议**：招牌沿 x 平移 2–3m，或旗杆前移 4m。
- **验收**：默认构图（`cam=-2,-30&cy=15`）下招牌完整可读。

### P0-6 阴影质量
- **现象**：角色/道具的阴影糊成一块黑斑（`spawn_final.png` 右侧），边缘呈块状。
- **原因**：shadow map 2048 / 覆盖 ±150m = **14.6cm/texel**，对 1m 级道具太粗。
- **建议**：二选一 —— ① 把 shadow camera 收到 ±90m 并跟随玩家；② 道具用接触阴影（贴地暗斑）替代实时阴影。
- **验收**：角色脚边阴影边缘清晰、无 20cm 以上块状跳变。

## 五、技术债 / 风险

1. **非 git 仓库** —— 目录下没有版本控制，改动不可回滚。建议 `git init` 后先提交一次基线。
2. **单文件 1816 KB** —— 已接近抖音内嵌/分享的舒适区上限；若再加 8 栋实拍立面（每栋约 60 KB base64）会到 2.3 MB 以上，需要考虑压缩率或按需加载。
3. **贴图全靠裁切放大** —— 现有 4 张瓦片源分辨率都在 300–500 px 级，放大到 512² 后天然偏软；这是当前"照片立面看着糊"的根因，换源比调材质有效。
4. **判断颜色必须用 `tools/shot.sh` 截图** —— 直出渲染与后期合成（HDR RT + bloom）色差很大，`readPixels` 只能做相对比较。

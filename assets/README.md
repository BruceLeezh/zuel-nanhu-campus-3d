# assets/ —— 引擎无关的建筑资产

```
assets/buildings/<楼名>.glb   # 单个建筑的完整几何 + PBR 材质（glTF 2.0 二进制）
tools/glb.mjs                 # 极简 GLB 写出器 + 结构校验（无三方依赖）
tools/build-asset.mjs         # 参数化建模器：spec → .glb
```

## 为什么这么做
- **引擎无关**：`.glb` 可被 three.js / Unity / Unreal / Blender 直接导入，先建模后选引擎不会返工。
- **逐栋可交付**：每栋一个文件，替换一栋不影响其他，便于「逐栋验收 → 合成地图」。
- **可校验**：`validateGlb()` 校验 magic/版本/块长度/JSON 可解析/accessor 边界，导出即自检。

## 用法
```bash
node tools/build-asset.mjs                # 导出全部
node tools/build-asset.mjs 逸夫图书馆      # 只导出一栋
```
